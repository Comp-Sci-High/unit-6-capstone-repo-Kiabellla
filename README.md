# GlowBlue Esthetics Website

This repository contains a simple client-side booking page for appointments.

## Structure

- `views/index.html` — booking page and service list
- `public/css/styles.css` — styling for the page
- `public/js/index.js` — booking logic and appointment display

## Usage

Open `views/index.html` in your browser to view the booking site locally.
